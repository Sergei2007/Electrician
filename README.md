# Electrician
Описание проекта:

Программный продукт для электриков — это специализированное приложение-калькулятор для расчета стоимости работ по электромонтажу и прокладке кабелей.

Главная идея проекта:

Обеспечить пользователей электромонтажниками удобным инструментарием для быстрого расчета стоимости работ: учесть кол-во розеток, протяженность кабелей, необходимые материалы и т.д., чтобы минимизировать риски ошибок в смете и ускорить процесс подготовки коммерческих предложений.

Функциональность проекта:

- Ввод количества розеток, длины кабеля (например, 100 метров), проложенных трасс, типа кабеля, диаметра и т.д.
- Вывод итоговой стоимости работ и пунктов сметы с детализацией.
- Экспорт сметы в файл (PDF/CSV).

Целевая аудитория:

Электрики-прорабочие, бригады, строительные компании, частные мастера, ответственные за составление смет и расчет бюджета.

Пример использования:

- Введите: количество розеток, длина кабеля (м., кабельный тип), трассы, материал, тарифы.
- Нажмите кнопку "Расчитать".
- Приложение выводит: общую стоимость работ, стоимость кабеля, материалов, стоимость монтажа, итоговую сумму и детализацию по позициям.
